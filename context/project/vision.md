# Vision

Provide one predictable Linux installation interface without erasing distribution boundaries.

```bash
pkg search ripgrep
pkg install ripgrep
pkg install ./vendor.deb
pkg remove ripgrep
```

The user should not need to understand whether an upstream vendor ships a `.deb`, `.rpm`, Arch package or tarball when the artifact can be safely adapted.

The project wins by **normalizing delivery**, not by pretending Linux distributions are identical.
