# v1 Target

v1 should feel like a coherent user-space package manager, not a distro replacement.

Expected:
- local + remote install;
- Debian/RPM/ALPM artifact ingestion for supported package classes;
- repository search;
- dependency closure through pkg catalog plus verified host capabilities;
- transactional upgrades;
- profiles/generations;
- GC;
- explicit trust diagnostics;
- robust doctor/recovery tooling.

Not required for v1:
- operating-system upgrades;
- kernel/driver management;
- transparent arbitrary maintainer scripts;
- full system package parity with apt/dnf/pacman;
- reproducible source builds.
